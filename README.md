# SynCondeX — Code Converter

A responsive React and TypeScript code conversion workspace with a Node/Express API. Conversions are generated by Google Gemini; no sample or fabricated output is returned by the service.

## Requirements

- Node.js 20 or newer
- A Google Gemini API key for live conversion

## Setup

From the project root:

```bash
npm install
npm --prefix frontend install
npm --prefix backend install
```

Copy `backend/.env.example` to `backend/.env` and set `GEMINI_API_KEY` to your Gemini API key. The key is read by the backend only and is never sent to the browser. Set `GEMINI_MODEL` if you want to use another compatible Gemini model.

Start frontend and backend together:

```bash
npm run dev
```

Or start each in its own terminal:

```bash
npm run dev:backend
npm run dev:frontend
```

The Vite development server is at `http://localhost:5173`; the API listens at `http://localhost:4000`. Without a configured key, the UI displays setup instructions and the backend returns a clear configuration error.

## Production build

```bash
npm run build
npm --prefix backend start
npm --prefix frontend run preview
```

The current preview setup serves the frontend separately from the API; configure your production reverse proxy to route `/api` to the backend. Set `FRONTEND_ORIGIN` to the deployed frontend origin.

## Features

- Day/night theme persisted locally; responsive two-editor layout.
- Searchable selectors for 20 languages, swapping, sample snippets, upload, paste, copy, download, output editing, fullscreen, and Ctrl/Cmd+Enter.
- Gemini-powered conversion with request/response validation, 50,000-character cap, structured summary and warnings, rate-limit and provider error messages.
- Last 10 conversion records are saved only in browser localStorage. They are not uploaded to the backend.
- Code submitted for conversion is sent to the configured Gemini provider. Do not submit secrets or sensitive code unless your provider terms and organization policy allow it.
